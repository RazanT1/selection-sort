    Why it is selection sort

    The large rows show how the counts grow, and two rows rule out the sorts that look like it.

    How the counts grow

    Sorted, reversed and shuffled input all give these same counts. When n doubles, comparisons grow ×4 and swaps ×2.

    C(n) = n(n−1)/2 → Θ(n²)
    S(n) = n−1 → Θ(n)
